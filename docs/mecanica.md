# Mecânica

## 1. Estrutura do Chassi

O projeto utiliza a estrutura física de um carrinho de controle remoto reaproveitado como base para a construção do veículo robótico.

O chassi possui quatro rodas e espaço interno para instalação dos componentes eletrônicos, baterias e sistema de controle.

## 2. Desenho Técnico

O desenho técnico do chassi, contendo suas dimensões e vistas, está disponível no arquivo abaixo:

## 3. Dimensões

- Comprimento: 25,7 cm
- Largura máxima: 11,635 cm

## 4. Componentes Instalados

- ESP32
- Ponte H L298N
- Baterias
- Motores elétricos
- Câmera

## 5. Montagem

Os componentes serão posicionados no chassi de forma a garantir uma boa distribuição de espaço, organização dos fios e estabilidade durante a movimentação do carrinho.
