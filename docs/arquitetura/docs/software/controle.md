# Software e controle:

## 1. Estrutura do software:

O software do veículo é executado no ESP32, responsável pelo processamento dos comandos e pelo controle do sistema.

## 2. Comunicação:

O sistema utiliza comunicação sem fio para receber os comandos enviados pela organização.



## 3. Controle:

Os comandos recebidos são processados pelo ESP32 e convertidos em ações de controle dos motores.

A lógica de controle contempla os comandos necessários para o deslocamento e a direção do veículo.

## 4. Desenvolvimento e testes:

Durante o desenvolvimento serão realizados testes para verificar:

- resposta dos motores;
- controle de velocidade;
- controle de direção;
- estabilidade e resposta do veículo.

As alterações e resultados obtidos serão registrados no `PROGRESSO.md` e no documento de testes.

## 5. Estado atual:

O sistema de software e controle encontra-se em desenvolvimento.
