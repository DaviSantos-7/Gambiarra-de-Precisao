# Projeto mecânico:

## 1. Visão geral:

Estrutura do carrinho, o sistema de tração, a disposição dos componentes e as peças necessárias para seu funcionamento.

## 2. Dimensões:

O veículo será desenvolvido respeitando as dimensões máximas estabelecidas no regulamento da competição:

- **Comprimento máximo:** 300 mm;
- **Largura máxima:** 200 mm;
- As dimensões consideram rodas, sensores, suportes e demais acessórios.

As dimensões definitivas serão registradas nos desenhos técnicos do projeto.

## 4. Estrutura do veículo:

A estrutura será definida de acordo com a disposição dos componentes mecânicos e eletrônicos, buscando garantir:

- fixação adequada dos componentes;
- estabilidade durante o deslocamento;
- espaço para os sistemas eletrônicos;
- acesso aos componentes para manutenção e ajustes;
- atendimento às dimensões estabelecidas para a competição.
